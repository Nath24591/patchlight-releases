# Patchlight

Patchlight shows which updates your Windows PC is waiting for, and which ones matter. It checks your apps (WinGet and Chocolatey), Windows Update, your NVIDIA graphics driver, GIGABYTE motherboard BIOS and Control Center, and your installed drivers, then puts security fixes first in plain English. Apps update with one click; drivers, BIOS and Windows get a link to the right place.

## Install

1. Open the [latest release](https://github.com/Nath24591/patchlight-releases/releases/latest) and download `Patchlight_<version>_x64-setup.exe`.
2. Run it. It installs for your Windows account only, with no admin prompt.

The installer isn't code-signed yet, so Windows may say "Windows protected your PC". Choose **More info**, then **Run anyway**.

Patchlight sits in the system tray, checks once a day and keeps itself up to date. You can turn off "Start with Windows" in its Settings.

Windows 10 or 11, 64-bit. This repository only holds releases; the source is private.
